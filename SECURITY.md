# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | Yes                |

## Reporting a Vulnerability

If you discover a security vulnerability in edit-reel:

1. Please do NOT disclose it publicly on GitHub Issues or Discussions.
2. Report the vulnerability privately via GitHub Security Advisories at:
   `https://github.com/MMhaidra/edit-reel/security/advisories/new`
3. Include details of the vulnerability, reproduction steps, and potential impact.

We take security seriously and will investigate and patch verified vulnerabilities promptly.
